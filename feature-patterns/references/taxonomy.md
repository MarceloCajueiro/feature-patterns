# Vocabulary for describing a feature

Use these words so reports compare cleanly across apps and across features.
They are generic interface terms, grouped the way a design-reference library indexes real products: by platform, by app category, by flow, by screen type and by UI element.
Pick the closest term; invent a new one only when nothing fits, and say so.

## The five facets

| Facet | Question it answers | Example values |
|---|---|---|
| Platform | Where does it run? | iOS, Android, web app, marketing website |
| App category | What kind of product is it? | finance, shopping, health and fitness, productivity, social, travel, education, food delivery, developer tools |
| Flow | What job is the user doing, step by step? | signing up, checking out, cancelling a subscription |
| Screen type | What is this one screen for? | paywall, empty state, settings, order confirmation |
| UI element | Which building blocks does the screen use? | bottom sheet, stepper, toast, segmented control |

A **flow** is an ordered list of **screens**.
Each screen has one **screen type** and several **UI elements**.
A **pattern** is a recurring combination of these across at least two apps.

## Flows (the job, as a verb)

- Account: creating an account, logging in, logging out, resetting a password, verifying identity, two-factor setup, switching account, editing profile, deleting or deactivating an account.
- First run: onboarding, onboarding questionnaire, permission requests, product tour, progressive onboarding, importing data, inviting teammates.
- Commerce: browsing, searching, filtering and sorting, adding to cart, checking out, paying, ordering, tracking an order, cancelling or refunding, redeeming a code, subscribing or upgrading, cancelling a subscription, gifting.
- Money: transferring money, requesting money, topping up, splitting a bill, linking a bank or card.
- Content: creating, editing, publishing, sharing, saving to a collection, favouriting or pinning, archiving, deleting, uploading or downloading, importing or exporting, reordering.
- Social: following, commenting or replying, liking, messaging, calling, reporting, blocking, muting, referring friends.
- Scheduling: booking or reserving, scheduling, rescheduling, joining an event.
- Settings: enabling or disabling a feature, switching theme, changing notification preferences, connecting or linking an account.
- Feedback: rating and reviewing, giving feedback, contacting support.

## Screen types

- Entry: splash, welcome or get started, signup, login, forgot password, verification code.
- Home and navigation: home, dashboard, feed, browse or discover, search, search results, filter and sort.
- Detail: product detail, item or post detail, profile, order detail, event detail, article.
- Commerce: cart, checkout, payment method, order confirmation, order history, pricing, paywall, billing.
- Feedback states: success or acknowledgement, error, empty state, loading, offline, confirmation dialog, permission prompt.
- Account: settings, preferences, notifications settings, privacy, account management, delete account.
- Help: help and support, FAQ, chat with support, feature announcement or what is new.

## UI elements

- Navigation: tab bar, top navigation bar, side navigation or drawer, breadcrumbs, segmented control, tabs, back button.
- Overlays: modal dialog, bottom sheet, action sheet, popover, tooltip, coach marks, full-screen overlay.
- Feedback: toast or snackbar, banner, inline validation, badge, progress indicator, stepper, skeleton, spinner.
- Input: text field, search bar, dropdown or picker, date picker, time picker, slider, switch, checkbox, radio button, chips, file upload.
- Actions: primary button, secondary button, floating action button, split button, swipe actions, pull to refresh, drag handle.
- Content: card, list, stacked list, table, carousel, gallery, avatar, empty-state illustration, chart, map.

## Website sections (for marketing sites)

Hero, navigation, social proof or logos, features, how it works, testimonials, pricing table, comparison table, FAQ, call to action, newsletter signup, footer, blog index, careers, contact form.
